# TASK-013 — Criterio culinario del asistente

El usuario muestra una propuesta de patys con fideos que solo enumera alimentos y cocción básica, sustituye el producto por bondiola y solicita permisos reiterados. Reforzar que el modelo diseñe una receta útil antes de calcular porciones, respetando productos y cantidades declarados, sin sumar otro generador ni un flujo de preguntas. Compartir las instrucciones con el MCP. Publicación directa autorizada; pruebas de uso a cargo del usuario.
