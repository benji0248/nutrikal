# TASK-010 — Interfaz conversacional del asistente

El usuario rechazó la interfaz experimental: exceso de explicación, configuración e información técnica alrededor del campo para conversar.

Objetivo: poner la conversación y escritura en primer plano, simplificar la entrada, llevar el historial y conexiones a controles secundarios y presentar las propuestas de manera progresiva. Mantener el chat clásico y los permisos/confirmaciones del calendario. Publicación directa autorizada; las pruebas funcionales quedan a cargo del usuario.
